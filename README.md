# Brandspire Media Website

A responsive, static Brandspire Media agency website.

## Files
- index.html — page structure/content
- css/style.css — design and responsive layout
- js/script.js — mobile navigation, reveal animations and year

## Before publishing
Replace the placeholder portfolio cards with Brandspire Media's real images and project information.
Update the About/Services copy with the final information from the business owner.

## Security included
- Strict Content-Security-Policy meta policy
- Referrer-Policy
- No third-party JavaScript libraries
- External Instagram link uses rel="noopener noreferrer"
- No passwords, payment details, or sensitive data are collected
- Contact uses a mailto link rather than storing form submissions

## HTTPS
Use a hosting provider that supplies a free TLS/SSL certificate and enable HTTPS. Redirect HTTP to HTTPS at the hosting layer. Do not put private API keys or credentials in this static site's files.
